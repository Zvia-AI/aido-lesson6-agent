# שיעור 6 - סוכן לניהול תקציב שיפוץ

תכננתי סוכן לניהול תקציב שיפוץ ולהשוואת הצעות מחיר. במהלך שיפוץ מגיעות עשרות הצעות מספקים, בפורמטים שונים: מסמכים, קובצי וורד ותמונות של הצעות בכתב יד. את ההצעות מעלים לתיקייה ייעודית בגוגל דרייב. פעם ביום הסוכן קורא את ההצעות החדשות, מחלץ מהן את הסעיפים והמחירים ומעדכן טבלת תקציב מרכזית בגוגל שיטס. בתחומים שיוצאים למכרז, כמו קבלן שיפוצים או נגר, הסוכן מציב עד שלוש הצעות זו לצד זו ומתריע כשספק השמיט סעיף שספקים אחרים כללו. הוא גם מזהה תלויות בין תחומים, למשל אסלה תלויה שמחייבת עבודת אינסטלציה ושבירת ריצוף. ערך לא קריא הוא מסמן לבדיקה ולא מנחש. הסוכן לא שולח מיילים לספקים, אלא רק מכין טיוטות לאישור.
